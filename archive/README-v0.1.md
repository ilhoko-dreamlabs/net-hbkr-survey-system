# AI Positioning Survey v0.1

## 범위
- Domain 선택
- AI Depth 행동 기반 설문
- Role / Capability 선택
- Production Maturity 선택
- 결과 Profile 생성
- AI Depth Shape / Positioning Matrix 표시
- 결과 복사 / JSON 저장

## 제외
- 프로젝트 매칭
- 회원가입
- 서버/DB 저장
- 외부 검증형 역량 인증

## 실행
`index.html`을 브라우저에서 열면 바로 실행됩니다.
